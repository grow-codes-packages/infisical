# TypeScript example

```sh
(cd ../../typescript && npm install && npm run build)
npm install
GROW_INFISICAL_URL=http://127.0.0.1:<port> GROW_INFISICAL_TOKEN=... npm start
```

Replace the `file:` dependency in `package.json` with a version (`npm install @grow-codes/infisical`)
to run it against the published package.
